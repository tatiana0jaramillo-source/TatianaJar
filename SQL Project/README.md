Español
Proyecto de limpieza de datos en SQL utilizando una base de datos pública de despidos. Primero creé una copia de seguridad para proteger los datos originales. Identifiqué y eliminé duplicados usando ROW_NUMBER(). Estandaricé los datos eliminando espacios, unificando categorías (como "Crypto"), corrigiendo países y convirtiendo fechas a formato DATE. Finalmente, traté valores nulos y eliminé filas sin información relevante. El resultado es una base de datos limpia y lista para análisis.

English
SQL data cleaning project using a public layoffs database. I started by creating a backup copy to protect original data. Identified and removed duplicates using ROW_NUMBER(). Standardized data by trimming spaces, unifying categories (like "Crypto"), fixing country names, and converting dates to DATE format. Finally, handled null values and removed rows with no relevant information. The result is a clean database ready for analysis.
