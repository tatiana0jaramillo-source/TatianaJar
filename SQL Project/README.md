## Español
Este proyecto consiste en la limpieza de una base de datos pública. El proceso incluyó la creación de una copia de seguridad para preservar los datos originales, la identificación y eliminación de duplicados con ROW_NUMBER(), y la estandarización de los datos mediante la corrección de espacios, unificación de categorías como "Crypto", normalización de países y conversión de fechas al formato DATE. También se gestionaron valores nulos y se descartaron filas sin información relevante, obteniendo así una base de datos depurada y lista para su análisis.

## English
This project involves cleaning a public database. The process included creating a backup to preserve the original data, identifying and removing duplicates with ROW_NUMBER(), and standardizing the data by correcting spaces, unifying categories like "Crypto", normalizing country names, and converting dates to DATE format. Null values were handled and rows without relevant information were removed, resulting in a clean database ready for analysis.
